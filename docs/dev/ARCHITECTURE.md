# Architecture

## Scope

`neuroutils` is organized as a composable toolkit for neuron morphology data.

## Module boundaries

- `neuroutils.io`
  - Parsers/writers and format adapters.
  - No metric logic in this layer.
- `neuroutils.validation`
  - Structural and schema-level checks.
  - Reusable by all higher layers.
- `neuroutils.transforms`
  - Coordinate transforms, normalization, and resampling.
- `neuroutils.morphometrics`
  - Geometry/topology statistics and feature extraction.
- `neuroutils.visualization`
  - Plotting and rendering adapters for validated/processed data.

## Design rules

- Keep I/O pure: deserialize/serialize only.
- Keep metric functions deterministic and side-effect free.
- Prefer typed public APIs and explicit data contracts.
- Add tests at module boundaries before implementation details.

## Packaging and delivery

- Build backend: setuptools.
- Wheel/sdist generated by `python -m build`.
- PyPI publishing via GitHub Actions trusted publishing.
